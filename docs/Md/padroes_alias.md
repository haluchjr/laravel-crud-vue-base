## LISTA DE APELIDOS (ALIASES) NO VUE
<div align="center">

| Nome Completo | Apelido (Alias) | O que faz |
| :--- | :--- | :--- | 
| **v-slot:header** | #header | Direciona o conteúdo para um slot nomeado. |
| **v-slot:default** | #default | (Opcional) Direciona para o slot padrão. |
| **v-on:click** | @click | Escuta um evento do navegador (clique, submit, etc). |
| **v-on:submit.prevent**| @submit.prevent | Escuta o envio do form e evita o reload da página.|
| **v-bind:href** | :href | Vincula um atributo HTML a uma variável/prop do Vue. |
| **v-bind:class** | :class | Vincula classes CSS dinâmicas. |
| **v-bind:src** | :src | Vincula o caminho de uma imagem dinamicamente. |
| **v-bind:title** | :title | Vincula o title da pagina |

</div>

## Padrao para nomes dos componentes
<div align="center">

| Tipo de Componente | Padrão Recomendado | Exemplo no seu código |
| :--- | :--- | :--- | 
| Gerais / Base	|        Começar com 'App' ou 'Base'	     |   AppModal.vue, AppButton.vue|
| Layouts	     |           Terminar com a palavra 'Layout'|	    CrudLayout.vue, AuthLayout.vue|
|Telas / Páginas|	        Nome direto da entidade + Ação	 |   ProjetoIndex.vue, ProjetoForm.vue|

</div>
