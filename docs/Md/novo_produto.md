# Adicionar novo produto via banco
- Incluir na *tb_produtos* o novo produto anotar o ID
- Incluir os componentes(partes do produto) na *tb_produtos_componentes* usando o ID 
    do tb_produto novo que usou e referencia da tb_componente(ID) e se o mesmo é requrediro(obrigatorio)
- Precisa vincular aquele produto as extensoes que serão aceitas, acesse *tb_produtos_componentes_extensao* vincule nele
    usando o ID fornecido na *tb_produto_componentes* (ID) e qual extesão será usada *tb_extensoes*
